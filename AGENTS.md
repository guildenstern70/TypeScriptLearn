# AGENTS.md

## Project Overview
`TypeScriptLearn` is a reference project designed to showcase various TypeScript features and patterns.

## Important Operational Notice
> [!IMPORTANT]
> **This project is not intended to be run directly as an executable application.** Instead, functionality and features are verified and demonstrated via the test suite (`npm run test`).

## Agent Instructions & Guidelines

### Building & Testing
- To install dependencies: `npm install`
- To run the test suite: `npm run test`
- To build/transpile TypeScript code: `npm run build`
- To format and fix lint issues: `npm run format`

### Code Style & Formatting
- Code formatting and linting rules are enforced with ESLint and Prettier.
- Run `npm run format` after making changes to ensure code style compliance.
- Keep tests concise and organized under `src/` (or test files following `*.test.ts` / `*.spec.ts`).
